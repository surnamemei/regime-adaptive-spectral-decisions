# Release portability

The scientific code and data originate from the local targeted-validation package. The release removes the optional scratch-directory import from two high-precision scripts and changes the original figure generator's data path to the repository layout. No numerical formula, seed, fit setting or stored record is changed. Project-only protected-file checks, author-declaration hashes, build logs and unused weak-identification scripts are excluded. The original and follow-up protocols and computational amendments are retained.

The deterministic companion has a separate repository and DOI. This code-and-data release contains no companion manuscript or interval-certificate forest.
