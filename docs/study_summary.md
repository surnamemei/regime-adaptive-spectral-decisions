# Regime-adaptive branch decisions for deficient-order fits of spectral clusters

Jinghang Mei

Current manuscript prepared for *Metrika*, updated 22 October 2026.

## Abstract

We study data-dependent selection between two tests whose calibration requires different noise regimes. The target is the branch preferred by the noiseless least-squares loss when a spectral signal is fitted with too few exponentials. A linear contrast test is calibrated when noise dominates the finite-spacing threshold displacement. A restricted fitting-cost test is calibrated when noise is small relative to the cluster defect. We select between them using an estimated noise-to-defect ratio and allow an inconclusive decision. Under a nondegenerate two-branch exchange condition, we prove uniform asymptotic control of the unconditional probability of a wrong declaration as cluster spacing tends to zero. Uniformity covers remote amplitudes near the limiting threshold, bounded noise-to-defect ratios and compact positive cluster classes. The overlap proof combines an exact selection identity with anti-concentration of an independent noise estimate. When the noise-to-defect ratio vanishes, a margin of many noise widths suffices for consistent correct declarations. The model assumes circular Gaussian noise, a known phase reference and a phase-opposed remote tone at known frequency. Finite-spacing operating curves show gains over cost-only testing at critical noise. Relative to requiring agreement between the tests, gains at critical noise accompany losses at weak noise.

## Keywords

uniform inference; adaptive testing; hypothesis testing; model misspecification; nonlinear least squares; spectral estimation
